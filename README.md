# Locus demo

A small workspace for trying [Locus](https://github.com/DanKrsi/locus): one note and one
flowchart that link into a PDF, some code, a spreadsheet, slides, an image and a recording,
across three versions.

## Open it

- **Easiest:** download `Locus-demo.locus` from the
  [Locus release](https://github.com/DanKrsi/locus/releases/latest) and double-click it.
- **With git:** `git clone https://github.com/DanKrsi/locus-sample.git`, then in Locus choose
  **Open a folder** and pick it. (A zip download won't work: the demo needs its version history.)

Then open **notes/Start here.md**, click any green link, or press **Tour**.
